──────────────────────────────
🔍 2. Détection des capteurs
──────────────────────────────
fichier : detect_local.py  
But : détecter automatiquement les entités physiques liées à la puissance ou à l’énergie.

Fonction principale : run_detect_local(hass, entry, mode_flux="complet")

├─ collect_power_entities(hass)
│   ├─ Parcourt hass.states.async_all('sensor')
│   ├─ Filtre ceux avec device_class in ("power", "energy")
│   ├─ Vérifie unit_of_measurement (W, kW, kWh)
│   └─ Retourne liste [{entity_id, attributes, state}]
│
├─ is_physical_power_entity(entity)
│   └─ Vérifie : unit=W + state_class=measurement
│
├─ regrouper_par_piece(entites)
│   └─ Extrait le nom de la pièce depuis entity_id (ex: salon_xxx → "salon")
│
├─ enregistrer_capteurs_detectes_async()
│   └─ Sauvegarde async → data/capteurs_detectes.json
│
└─ update_sensor_entities_par_piece()
    └─ Met à jour sensor.home_suivi_elec_entites_par_piece dans hass

──────────────────────────────
🧩 3. Génération de la configuration
──────────────────────────────
fichier : generator.py  
Objectif : générer YAML pour la configuration Home Assistant et les vues Lovelace.

├─ slugify() / normalize_name() → nettoyage ID
├─ build_integrations_capteurs()
│   └─ Structure {integration: {actifs: [], exclus: []}}
│
├─ generate_yaml_config(capteurs)
│   ├─ input_number prix_kwh
│   ├─ platform: integration (power sensors)
│   ├─ utility_meter (daily/weekly/monthly/yearly)
│   └─ template sensors coût (€)
│
├─ generate_lovelace_grid()
│   └─ YAML Lovelace : vue “Consommation par pièce”
│
├─ generate_lovelace_history()
│   └─ YAML Lovelace : vue “Historique énergétique”
│
├─ generate_lovelace_file_auto()
│   └─ Écrit lovelace_auto.yaml dans /config/
│
└─ run_all()
    ├─ Appelle generate_yaml_config()
    ├─ Appelle generate_lovelace_grid() + history
    └─ Appelle generate_lovelace_file_auto()
