# 🤝 Contribuer à Home Suivi Élec

Merci de vouloir contribuer à l’évolution de l’intégration !
Voici comment proposer des améliorations, rapports de bug ou nouvelles fonctionnalités.

---

## 📦 Organisation du projet

- Backend : `custom_components/home_suivi_elec/`
- Frontend : `custom_components/home_suivi_elec/web_static/`
- Data : `custom_components/home_suivi_elec/data/`
- Docs : `docs/`

---

## 🛠️ Proposer une évolution ou corriger un bug

1. Ouvrir une issue sur Github avec :
   - Description claire du problème ou de la proposition
   - Screenshots ou logs (si applicable)
2. Forker le repo et travailler sur une branche dédiée
3. Respecter les conventions :
   - Un commit par fonctionnalité ou bug
   - Tests unitaires ou manuels recommandés
   - Ajout ou adaptation de la documentation si nécessaire

---

## 📝 Style et bonnes pratiques

- Privilégier le typage strict en Python et JS
- Documenter toute fonction critique ou toute modification de structure (data/JSON)
- Préférer les logs clairs : `[DEBUG]`, `[REST]`, `[SETUP_ENTRY]`…
- Toujours mettre à jour la roadmap si vous ajoutez une feature
- Vérifier la pérennité et l’utilité des modules/fichiers existants avant toute PR de nettoyage
