# 🛠️ Roadmap — Home Suivi Élec

Liste des évolutions, idées et TODO à court et moyen terme.

---

## ⚡ Fonctionnalité à terminer ou améliorer

- Génération des cartes Lovelace (module generator.py et panel_static/)
- Intégration/synchronisation automatique Utility Meter avec les sélections UI
- Amélioration du support des capteurs “externe” (Atome ou autres)
- Ajout d’indicateurs visuels pour les nouveaux capteurs après détecton
- Customisation renforcée : thèmes, grille, widgets “pièce”
- Automatisation totale des sauvegardes et du refresh dans l’UI

---

## 💡 Idées et évolutions futures

- Statistiques consolidées (historiques, comparaison sur période)
- Intégration native HACS (publication officielle Home Assistant)
- API REST “contributeurs” pour debug et extension tierce
- Mode “expert” : logs détaillés, validation, gestion avancée

---

## 🐞 Bugs connus ou cas limites

- Sélection/désélection multiple parfois instable
- Capteurs externes non détectés automatiquement dans certains cas
- Rafraîchissement du résumé en cas de suppression de capteur : à fiabiliser

- Toute suggestion ou PR est bienvenue via le repo GitHub
